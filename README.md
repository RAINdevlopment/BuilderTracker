# BuilderTracker

A full-stack construction project management app built with ASP.NET Core and React.

Built to practice skills for a SWE internship at Buildertrend.

## Tech Stack

- **Backend:** ASP.NET Core 8 Web API (C#) — IDesign architecture
- **Frontend:** React + TypeScript (Vite)
- **Database:** SQLite + Entity Framework Core
- **Version Control:** Git + GitHub

## Project Structure

```
BuilderTracker/
├── src/
│   ├── BuilderTracker.API/        # ASP.NET Core Web API
│   └── BuilderTracker.Client/     # React frontend
└── README.md
```

## Features

- Manage construction projects
- Track tasks per project
- Assign tasks to team members
